01 / How it works

Play, compare, borrow

Every skin runs on this same markup. Switching takes one click, or one arrow key.

A

Switch the skin

The bar at the bottom switches between twenty-four design styles. No reload, no settings to learn, and your choice is waiting next time you visit.

  • Bottom switcher
  • Arrow keys
  • Saved preference
See all 24 styles →
B

Read the decisions

Each skin is one CSS file with its own type scale, palette, corners and surfaces. Open a file and the reasoning is all there, nothing compiled away.

  • One file per style
  • Plain CSS
  • Easy to diff
Browse the stylesheets →

Take what fits

Use a palette, a heading treatment or a whole skin. The MIT licence allows reuse and modification; keep the copyright and licence notice with the code.

  • MIT licensed
